# Cal Py Tools: examples

In this folder you can find some scripts to test **CalPyTools**. Remember that you will need
[music21](https://web.mit.edu/music21/) to create music. Get some fun with:

- **working_with_pcs.py**: to see how to use **PCS()** in your code.
- **building_counterpoints.py**: to create music using **Counterpoint()**. Output files will be saved at
*output* folder. The comments in the code should guide you.
- **building_textures.py**: to create music using **Matrix()**. A *Texture* is similar to a *Counterpoint*
but pitch is completely controlled by a *matrix*.
